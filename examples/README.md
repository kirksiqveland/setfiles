# Set File Examples

This folder contains example Set files demonstrating various features and use cases.

**Note:** These examples were created for SET File Format v4.0 and are fully compatible with v4.2.

## Available Examples

* **[simple-config.set](simple-config.set)** - Basic configuration with key-value pairs
* **[database-records.set](database-records.set)** - Tables with field definitions and multiple related data sets
* **[test_data_complete.qset](test_data_complete.qset)** - Comprehensive test file covering all features and edge cases

## For More Detail

See **[Examples.md](Examples.md)** for detailed descriptions, use cases, and explanations of what each example demonstrates.

## Using These Examples

You can:
- View them in any text editor
- Use them as templates for your own Set files
- Test them with Set file parsers
- Modify them to explore different features
